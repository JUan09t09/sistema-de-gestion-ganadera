⚙️ Configuración inicial

Conecta Firebase para sincronizar entre dispositivos (gratuito).

1 Ve a console.firebase.google.com e inicia sesión.
2 Crea un proyecto → nombre (ej: mi-finca) → desactiva Analytics → Crear.
3 Ícono </> (Web) → registra la app → copia firebaseConfig.
4 Authentication → Email/Contraseña → Habilitar.
5 Firestore → Crear base de datos → Modo prueba → Listo.
🔒 Privacidad: Tu configuración se guarda solo en este navegador.

Descripción de roles

👑 Propietario

Acceso total. Crea y gestiona usuarios.

Todo excepto gestión de usuarios y configuración.

Salud, vacunas y reproducción. Ve animales.

Registra pesajes de ganado. Ve animales.

👁️ Solo lectura

Ve todo pero no puede editar ni registrar nada.

👤 Nuevo usuario

Después de crear el usuario, el sistema mostrará el Código de finca y los datos de acceso para compartir con el trabajador. Él los ingresa en la pantalla de login → pestaña "Soy trabajador".
